# 示例

这些是**真实的开发过程记录**，不是精心构造的 demo。

## dryrun-01 —— 第 6 页（原生矢量）

第一轮完整跑通：标号确认 → 问任务 → 画 → 改。
包含**我犯的一个错和它的全过程**：把用户的回答"折线"误解成"一条关系"，
结果重画时删掉了一个箭头。

结果：PPT 版和原图的显著差异像素 **8.0%**。

## dryrun-02 —— 第 5 页 B 区（原生矢量，复杂）

第二轮，换了个更难的：四层架构 + 内嵌流程图 + 6 张位图图标 + 旋转的括号。
用户报了两轮问题，每一轮都查到了根因。

结果：**7.1%**（手工精修）／**7.7%**（通用脚本，scripts/ 里那套）。

## dryrun-01/render 与 dryrun-02/orig 里的图
