## 为什么分两份

**决策**会被改主意作废；**证据**不会。混在一起，改决策时会顺手把证据也改掉。

## 一句话说清这份文档和 `../` 的关系

`需求与目标.md` 描述的是**下一个版本要做成什么样**，范围比当前发布的 v0.1 大得多。

`../README.md`（产品 README）和 `../skills/` 描述的是**现在这一版实际能做什么**——**只覆盖 PPT 里的原生矢量图**。
两者不一致是**预期的**：文档写目标，代码写现状。

⚠️ 反过来也成立：**`../` 里的实现是"某一版的快照"，不是项目边界。** 边界由 `需求与目标.md` 决定。
